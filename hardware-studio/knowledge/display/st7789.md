# ST7789 彩色 TFT-LCD 控制器（ST7789V，及常见 SPI 小彩屏模块）

一句话：Sitronix 的 240×320、262K 色 TFT 单芯片驱动/控制器，内置帧存储，常以 1.3–2.0 寸 SPI 小彩屏模块出现；做表情、图标、简单动画的主力。

> 数据手册来源说明：Sitronix 官网本会话不可达。本页读自 GitHub 第三方仓库 libdriver/st7789 托管的 **ST7789V Datasheet Version 1.3（2014/03）**，因非官方托管全部标"待核实"。市面模块常标 ST7789VW 等变体，与 ST7789V 的差异未查到。

## 易踩的坑

| 坑 | 说明 / 对策 | 来源 |
|---|---|---|
| SPI 时钟按"能跑就行"拉到几十 MHz | 手册写的写周期下限是 66 ns（≈15 MHz）；超频能否工作取决于具体批次和走线，属于超规格使用 | [ST7789V V1.3 表 6](https://github.com/libdriver/st7789/blob/7bd8bc794bea273b934fffac4a73133ee0eb7ebf/datasheet/st7789_datasheet.pdf) · S（镜像）· 2026-11-01 · 待核实 |
| 复位后立刻发 Sleep Out | 要等 120 ms，否则初始化不稳定 | [ST7789V V1.3 表 9 注 7](https://github.com/libdriver/st7789/blob/7bd8bc794bea273b934fffac4a73133ee0eb7ebf/datasheet/st7789_datasheet.pdf) · S（镜像）· 2026-11-01 · 待核实 |
| 只关了 LCD 没关背光 | Sleep-in 时控制器只剩约 15 μA，但背光照样耗电；背光要用 GPIO/MOS 单独关断 | [ST7789V V1.3 §7.3 表 3](https://github.com/libdriver/st7789/blob/7bd8bc794bea273b934fffac4a73133ee0eb7ebf/datasheet/st7789_datasheet.pdf) · S（镜像）· 2026-11-01 · 待核实 |
