# SSD1306 单色 OLED 控制器（及常见 0.96 寸 128×64 模块）

一句话：Solomon Systech 的 128×64 单色 OLED 驱动/控制器，内置电荷泵，I2C 或 SPI 接口；最省事的"小字屏"，几乎所有 MCU 平台都有现成驱动。

> 数据手册来源说明：Solomon Systech 官网本会话不可达。本页芯片参数读自 GitHub 上第三方仓库 libdriver/ssd1306 托管的原厂 PDF（SSD1306 Rev 1.5，Aug 2010，"Advance Information"），因非官方托管，所有行标"待核实"，以官方版本复核为准。
