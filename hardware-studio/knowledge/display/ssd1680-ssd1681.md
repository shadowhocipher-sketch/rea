# SSD1680 / SSD1681 墨水屏（EPD）控制器

一句话：Solomon Systech 的有源矩阵电子纸驱动/控制器，SSD1680 最大 176×296（常见 2.13/2.9 寸屏），SSD1681 最大 200×200（常见 1.54 寸屏）；黑白或黑白红三色，SPI 接口，断电保持画面，深睡电流约 1 μA。

> 数据手册来源说明：Solomon Systech 官网本会话不可达。SSD1680 读自 GitHub 仓库 CursedHardware/epd-driver-ic 托管的 **SSD1680 Rev 0.14（Jun 2019，Product Preview）**；SSD1681 读自 libdriver/ssd1681 托管的 **SSD1681 Rev 0.13（May/Jun 2019，Product Preview）**。均非官方托管，且是"Product Preview"版本，全部标"待核实"。
> **刷新时间不是控制器参数**：它由面板的波形表（LUT）和温度决定，控制器手册里没有给，要看面板（如大连佳显 Good Display）的规格书。

## 易踩的坑

| 坑 | 说明 / 对策 | 来源 |
|---|---|---|
| 不等 BUSY 就发下一条命令 | BUSY 高时命令不应发送；每次 Master Activation、软复位后都要轮询 BUSY 或用中断 | [SSD1680 Rev0.14 §5 BUSY](https://github.com/CursedHardware/epd-driver-ic/blob/8c147a71ff451da3b16450162559cb0ccd8bdaec/SSD1680.pdf) · S（镜像）· 2026-11-01 · 待核实 |
| 深睡后发命令没反应 | 退出深睡只能硬件复位（RES#），所以 RES# 必须接 MCU GPIO，不能只接 RC | [SSD1680 Rev0.14 命令 10h](https://github.com/CursedHardware/epd-driver-ic/blob/8c147a71ff451da3b16450162559cb0ccd8bdaec/SSD1680.pdf) · S（镜像）· 2026-11-01 · 待核实 |
| 深睡 Mode 2 后局刷花屏 | Mode 2 不保留 RAM；需要基于旧画面做局刷时要用 Mode 1 或重写 RAM | [SSD1680 Rev0.14 表 11-1](https://github.com/CursedHardware/epd-driver-ic/blob/8c147a71ff451da3b16450162559cb0ccd8bdaec/SSD1680.pdf) · S（镜像）· 2026-11-01 · 待核实 |
| 把"刷新时间"当控制器参数 | 刷新时间由面板 LUT 和温度决定，换面板/换温度会变；产品交互（如答题翻页）要按面板实测设计 | [SSD1681 Rev0.13 §6 波形设置](https://github.com/libdriver/ssd1681/blob/db14fa9ad397e25fcf5589f042cbf58b8fec2be6/datasheet/ssd1681_datasheet.pdf) · S（镜像）· 2026-11-01 · 待核实 |
