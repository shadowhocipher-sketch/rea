# MAX17048 单节锂电电量计（fuel gauge）

一句话：Maxim（现属 Analog Devices）的单节锂电电量计，用 ModelGauge 算法只测电池电压就估算电量百分比（SOC），不需要检流电阻、不需要学习循环；I2C 接口，休眠时 3 μA；外围只有一个 0.1 μF 电容。适合"屏幕上显示电量百分比"的小产品。同系列 MAX17049 是两节串联版本。

> 数据手册来源说明：analog.com 本会话不可达。本页读自 GitHub 仓库 porcinus/FreeplayBatteryDaemon 的 docs/MAX17048-MAX17049.pdf（Maxim 文档 19-6171 Rev 7，2016 年 11 月，19 页，文本可提取），非官方托管，标"S（镜像）· 待核实"。官方地址（来自搜索摘要，未打开）：https://www.analog.com/media/en/technical-documentation/data-sheets/MAX17048-MAX17049.pdf 。
