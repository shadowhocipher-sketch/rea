# XC6206 超低静态电流 LDO（以 3.3 V 版本为例）

一句话：特瑞仕（Torex）的 3 端 CMOS LDO，静态电流典型 **1.0 μA**，适合"大部分时间深睡"的电池产品；但最大输出电流只有约 200 mA、压差偏大，**带不动 ESP32 Wi-Fi 峰值**，适合给传感器、墨水屏等小负载单独供电，或配合更大电流的主 LDO 使用。

> 数据手册来源说明：Torex 官网本会话不可达。本页读自 GitHub 仓库 STM32-base/STM32-base.github.io 托管的 **XC6206 Series ETR0305_008**，非官方托管，标"待核实"。
