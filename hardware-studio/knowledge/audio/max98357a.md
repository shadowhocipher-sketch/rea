# MAX98357A I2S 数字输入 D 类功放

一句话：ADI（原 Maxim）的单声道 PCM 输入 D 类功放，吃 I2S（MAX98357B 为左对齐）数字音频直接推喇叭，不需要 MCLK、不需要 I2C 配置；ESP32 加一颗它就能放语音、音效。

> 数据手册来源说明：analog.com 本会话不可达。本页读自 GitHub 仓库 Xinyuan-LilyGO/LilyGo-HAL 托管的 **MAX98357A/MAX98357B 数据手册 19-6779 Rev 13（7/19）**，非官方托管，标"待核实"。除注明外，电气条件为 VDD=5 V、GAIN_SLOT=VDD、BCLK=3.072 MHz、LRCLK=48 kHz。
