# 量产路线决策表

三条路线：

- **A 开发板直接装**：买现成开发板（例如 ESP32-S3 开发板），和屏幕、电池等模块用排针/线连接，装进外壳。
- **B 模组 + 自画底板**：买认证过的无线模组（例如 ESP32-S3-WROOM-1），自己画一块底板，交给 JLCPCB 这类平台贴片。
- **C 自画整板（芯片级）**：直接用芯片（例如 ESP32-S3 QFN56）+ 晶振 + flash + 射频匹配 + 天线，全部自己设计。

本页的数字分三种：带链接的是查到的（价格来自 `mfg/prices/`，状态见那里）；标"估算"的是用公式推出来的；标"未查到"的是需要补的。日期 2026-11-01。
法规和认证的具体要求不在这里展开，看 `compliance/`（E 线）。

## 2. 示例：A 和 B 的单台成本

用 `mfg/cost.py` 跑两个通用示例（`mfg/examples/route-a-devboard.bom.csv`、`route-b-module.bom.csv`），两份 BOM 都含 0.96 寸 OLED 模块、15 g MJF 外壳、包装和组装人工；B 另有模组、LDO、USB-C、阻容、按键、PCB 和贴片费。命令：

```bash
python mfg/cost.py mfg/examples/route-a-devboard.bom.csv --qty 10 100 1000 --out mfg/examples/out/route-a-devboard
python mfg/cost.py mfg/examples/route-b-module.bom.csv  --qty 10 100 1000 --out mfg/examples/out/route-b-module
```

结果（USD，2026-11-01 实际运行；**估算**，因为输入里有待核实和估算的价格）：

| 数量 | A 单台 | B 单台 | A 中实查金额占比 | B 中实查金额占比 |
|---:|---:|---:|---:|---:|
| 10 | 13.75 | 16.17 | 41.3% | 2.8% |
| 100 | 12.08 | 13.44 | 37.5% | 2.5% |
| 1000 | 11.42 | 12.53 | 39.7% | 2.1% |

怎么读：

- 这个例子里 A 反而便宜，原因是立创自有品牌的 ESP32-S3 开发板（$4.45@100+）比我们按保守值记的 WROOM-1 模组价（$5.12，待核实）还低。
- 结论对模组价很敏感：如果模组实际是 $3.71（摘要里的另一个数），B 每台少约 $1.44（= (5.116 − 3.7069) × 1.02 损耗），1000 台时 B 约 $11.10，比 A 的 $11.42 便宜。**先把模组价核实了再下结论。**
- 两条路线的组装分钟数（A 10 分钟、B 5 分钟）和工时费都是假设值（`est:assembly-labor`），换成实际报价后重新跑。
- B 的实查占比很低，因为最贵的几项（模组、外壳材料、贴片费）都还是待核实。这正是 `cost.py` 输出这一列的用途。

## 3. 分界点公式（估算方法）

设数量为 N：

- A → B：当 `N × (a_unit − b_unit) > b_once` 时换 B。
  - `a_unit`、`b_unit`：两条路线的单台成本（用 `cost.py` 在同一数量档上算，含组装人工）；
  - `b_once`：B 的一次性成本 = 贴片工程费 + 钢网 + 扩展料换料费（`cost.py` 输出的"其中一次性费用"）+ 画板和打样的时间成本（自己估）。
  - 即使单台成本差不多，也会因为**尺寸、可靠性（不用手工接线）、外壳不再迁就开发板**而换 B——这些不是成本问题，按产品要求判断。
- B → C：当 `N × (b_module − c_chip_bom) > c_once` 时换 C。
  - `b_module − c_chip_bom`：模组价减去"芯片 + 晶振 + flash + 射频匹配器件 + 多出来的焊点费"；
  - `c_once`：射频调试（仪器或外包）、整机射频认证比模组方案多出的部分、多一到两轮打样。
  - 这几项本次都**未查到**，用到时按 `mfg/pricing.md` 查价、找认证机构报价，再代公式。
