# d01 · D 成本 · BOM + 价格表在 100 / 1000 台的单价（与手算核对）

**需求**：报价前要知道 100 台和 1000 台时每台多少钱；阶梯价、最小起订量、损耗、"多买到下一档反而便宜"、
一次性工程费、按焊点计费、扩展料换料费都要算对。

**任务**：`python mfg/cost.py evals/tasks/d01_cost_hand_calc/bom.csv --prices evals/tasks/d01_cost_hand_calc/prices.yaml --qty 100 1000 --out <dir>`，
读 `summary.csv`。价格是虚构的测试数据，只考算术。

**标准答案（手算，规则见 mfg/README.md 第 4 节；默认损耗 2%，process 行不计损耗，PKG1 损耗写 0）**

100 台：
| 行 | 需求 → 采购 | 单价 | 小计 |
|---|---|---|---|
| U1 | 1×100×1.02 = 102 | 2.40 | 244.80 |
| R1-R4 | 4×100×1.02 = 408 | 0.002（1000 档 1.20 > 0.816，不多买） | 0.816 |
| C1-C3 | 3×100×1.02 = 306 → 多买到 500（500×0.01 = 5.00 < 306×0.03 = 9.18） | 0.01 | 5.00 |
| DS1 | 102 | 2.00 | 204.00 |
| PCB1 | 100（不计损耗） | 0.80 | 80.00 |
| SMT1 | 1 批 | 8.00 | 8.00 |
| SMT2 | 每台焊点 40 + 2×4 + 2×3 = 54 → 5400 | 0.002 | 10.80 |
| SMT3 | 扩展料 1 种 | 3.00 | 3.00 |
| PKG1 | 100 | 0.30 | 30.00 |
合计 586.416，**单台 5.86416**；实查 250.616 / 待核实 225.80 / 估算 110.00。

1000 台：U1 1020×2.10 = 2142.00；R 4080 → 多买到 5000×0.0008 = 4.00；C 3060×0.01 = 30.60；DS1 1020×1.80 = 1836.00；
PCB1 800.00；SMT1 8.00；SMT2 54000×0.002 = 108.00；SMT3 3.00；PKG1 300.00。
合计 5231.60，**单台 5.2316**；实查 2176.60 / 待核实 1955.00 / 估算 1100.00。BAT1 是 DNP，不计。

**判分**：退出码 0、无缺价格行（0.1）；100 台单台（0.3）；1000 台单台（0.3）；两档的实查/待核实/估算金额（0.3），容差按 summary.csv 的舍入位数取：单台 ±0.00006、金额 ±0.006。
