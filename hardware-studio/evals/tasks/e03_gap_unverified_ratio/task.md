# e03 · E 合规 · 【缺口探测】法规条目"待核实"比例

**需求**：合规清单要能拿去问检测机构报价；"待核实"太多时清单只能当线索。

**任务**：统计 `compliance/data/requirements.yaml` 里 `status: 待核实` 的条目占比。降低的办法：能打开官方站点时按
compliance-map skill 的"怎么更新法规条目"逐条核对原文（S 级）+ 官方解读（A 级），把核实过的改成"已核实"。

**判分**：目标 待核实比例 ≤ 20%。得分 = min(1, 0.20 / 实际比例)；另外，任何一条待核实没写 `doubts`（疑点）、
或任何一条没有来源链接，直接 0 分。

这是缺口题：2026-11-01 基线时 52 条里 23 条待核实（约 44%），不满分是预期的。
